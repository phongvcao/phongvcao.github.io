# phongvcao.github.io

Static personal site for Phong V. Cao, served by GitHub Pages at https://phongvcao.com. The page is a hand-written OpenCode-style TUI in Solarized Dark: edit `index.html` for copy and structure, `styles.css` for the visual system, and replace `assets/phong-cao-resume.pdf` to update the resume; commit to `main` and GitHub Pages builds automatically.
